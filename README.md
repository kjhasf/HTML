## HTML: структура веб-сторінок (поглиблене вивчення)

### 🎯 Мета
Сформувати в учнів 10–11 класів поглиблені знання та практичні навички роботи з HTML для створення структурованих, семантичних та адаптивних веб-сторінок. Розвинути критичне мислення щодо якості та доступності веб-контенту.

Автор: Бойко Єлизавета АЗЛ-23
---

### 📚 Очікувані результати навчання
- **Запам’ятати:** основні HTML-теги, атрибути та структуру документа.  
- **Зрозуміти:** призначення семантичних тегів та відмінність між структурою й оформленням.  
- **Застосувати:** створювати базові веб-сторінки з використанням HTML5.  
- **Аналізувати:** перевіряти код на семантику, доступність та валідність.  
- **Оцінювати:** оцінювати якість веб-сторінок за критеріями UX та стандартами W3C.  
- **Створювати:** розробляти власні багатосторінкові сайти з правильною структурою та навігацією.
