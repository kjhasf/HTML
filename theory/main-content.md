# 📖 Глосарій термінів з HTML

## Основні поняття

- **HTML (HyperText Markup Language)** — мова розмітки гіпертексту, що використовується для створення структури веб-сторінок.
- **Тег (Tag)** — елемент HTML, який визначає структуру або зміст документа. Записується у кутових дужках `< >`.
- **Атрибут (Attribute)** — додаткова інформація про тег, що уточнює його властивості (наприклад, `src`, `alt`, `href`).
- **Елемент (Element)** — повна конструкція, що складається з відкриваючого та закриваючого тегів і вмісту між ними.
- **Доктайп (DOCTYPE)** — оголошення типу документа, яке визначає стандарт HTML, що використовується.

---

## Структура документа

- **`<html>`** — кореневий елемент HTML-документа.
- **`<head>`** — секція з метаданими (назва сторінки, стилі, скрипти).
- **`<body>`** — основний вміст сторінки, який бачить користувач.
- **Мета-теги (`<meta>`)** — описують додаткову інформацію про сторінку (кодова сторінка, ключові слова, опис).

---

## Семантичні теги

- **`<header>`** — верхня частина сторінки або розділу.
- **`<nav>`** — блок навігації.
- **`<main>`** — основний контент сторінки.
- **`<section>`** — тематичний розділ контенту.
- **`<article>`** — самостійний блок інформації (наприклад, стаття).
- **`<footer>`** — нижня частина сторінки або розділу.

---

## Контент та мультимедіа

- **`<h1>`–`<h6>`** — заголовки різних рівнів.
- **`<p>`** — абзац тексту.
- **`<a>`** — гіперпосилання.
- **`<img>`** — зображення.
- **`<audio>`**, **`<video>`** — мультимедійні елементи.
- **`<table>`** — таблиця.
- **`<form>`** — форма для введення даних.

---

## Додаткові поняття

- **Валідність HTML** — відповідність коду стандартам W3C.
- **ARIA-атрибути** — атрибути для забезпечення доступності веб-контенту.
- **SEO (Search Engine Optimization)** — оптимізація сторінки для пошукових систем.
- **WCAG (Web Content Accessibility Guidelines)** — міжнародні стандарти доступності веб-контенту.
